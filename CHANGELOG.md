# Changelog

## 0.2.0 - Chinese localization
- Add English and Simplified Chinese UI translations
- Add a language selector under personalization settings
- Apply language changes immediately without restarting the plugin
- Persist the selected language across reloads and restarts
- Default existing and legacy installations to English
- Localize dates, document metadata, accessibility labels, placeholders, tooltips, and agent prompts
- Keep feed names, article titles, summaries, and other external content in their original language
- Add automated coverage for translations, preference validation, persistence, and legacy data recovery
- Add browser test scenarios for switching languages and retaining the selection after reload

## 0.1.0 — initial release preparation, 2026-11-08

- RSS/Atom, Hacker News and public Reddit feeds in Orca’s right sidebar.
- Continuous list with inline expansion; opening another story closes the previous row and question form.
- Search, provider/source filters, unread state and durable saved snapshots.
- Opt-in developer RSS starters and tech subreddit suggestions, with one-click following and duplicate detection.
- Feed-supplied thumbnails and expanded images, loaded lazily and transferred in bounded parts.
- Ask Codex, Claude or Gemini in a fresh workspace conversation, with confirmed question delivery and durable retries.
- Light/dark appearance, compact headlines, keyboard controls and locally bundled Geist.
- Cached startup, per-source errors, atomic storage, manual refresh and optional focused-panel refresh.
- Patched XML parser, bundled runtime dependencies, complete notices and reproducible artwork/package tooling.

This entry describes the prepared build; it does not announce publication.
