# Orca plugin TypeScript declarations

These six declaration files are an unmodified snapshot generated by the official Orca **1.4.255** CLI with `orca plugin types`. They describe the public plugin API and contain no runtime implementation or local workspace data. The upstream MIT license is included in [LICENSE](LICENSE).

The root TypeScript configuration includes this snapshot directly. A fresh checkout can build and typecheck with Node.js 22+ and `npm ci --prefix build`; it does not need an installed Orca app or the ignored `.orca/types/` directory. Local SDK generation cannot change which declarations the project checks against.

When updating the supported SDK, generate declarations with the chosen Orca CLI and copy each `.orca/types/orca*/index.d.ts` to its corresponding `build/types/orca*.d.ts` file. Update this provenance and license if needed, then run the typecheck, logic tests, and host tests with that Orca version before committing the snapshot. Keep the generated `.orca/` directory ignored.

Source: https://github.com/stablyai/orca/tree/v1.4.255
